# 建模与检查记录

[English](README.md) · **简体中文** · [示例](../README.zh-CN.md)

Codex 根据提供的关节模组剖切图，用 build123d 建立 20 mm 孔径的装配，再将孔径扩大到 30 mm，保持外形尺寸和安装孔位不变。

| 记录 | 内容 |
|---|---|
| [20 mm 建模](model-20.json)、[30 mm 建模](model-30.json) | 代码、配置和导出 STEP 的哈希，零件数量与耗时。 |
| [检查汇总](check.json) | 检查耗时，以及重叠、接触、通孔堵塞和螺钉装入通道堵塞的对照测试。 |
| [20 mm 几何](check-bore-20.json)、[30 mm 几何](check-bore-30.json) | 实体有效性、STEP 导入导出一致性、通孔与安装孔尺寸、轴承间隙、干涉、螺钉装入和剖切检查。 |
| [改参对比](revision.json) | 八个部件随孔径变化；外包络及扩孔区域之外的安装几何不变。 |

本轮细化增加了密集绕组、绝缘骨架、圆弧磁钢、齿形圆角和轴承滚道。检查前端螺钉时，发现孔口边缘遮挡了装入通道，随后将沉孔完整打开。检查程序现会将每颗螺钉的头部和杆部包络从前方扫到安装位置。

每个版本包含 91 个命名部件、510 个实体。干涉检查筛查全部 4,095 个部件对，对包围盒重叠的部件做精确相交计算，也检查复合部件内部的实体。报告覆盖建模得到的静态几何，未计算齿形变形、轴承预紧和扭矩。

从这些 STEP 部件导出网格和曲面法线，交给 Blender Cycles 渲染，再由 HyperFrames 添加文字和对比布局。源文件和渲染记录见 [video/](../video/)。
