# Contributing

Suggest open-source software that helps automate a concrete part of mechanical CAD work: modeling, editing, assembly, inspection, drawings, file exchange, or evaluation.

## Suggest a tool or report a problem

Open an [issue to suggest a tool](https://github.com/jason-wjs/awesome-agentic-cad/issues/new) to share a repository link and a sentence about its use. Experience reports and examples are helpful, but optional.

Open an [issue](https://github.com/jason-wjs/awesome-agentic-cad/issues/new) for broken links, outdated descriptions, or setup problems.

Issues and PRs can be in English or Chinese. Editing one README is enough; maintainers can help sync the other language.

## Submit a PR

For each addition:

- Link the upstream repository and explain its use in one sentence.
- Put it under the workflow step where a reader would look for it.
- Mention a requirement or release status when it affects getting started.
- Add a documentation or example link when available, and record the source in [curation-notes.md](docs/curation-notes.md).
- Update both READMEs if you can; otherwise, note which translation needs syncing.

A useful library can belong here without an AI feature. Research code belongs when it offers a tool people can use. Papers can accompany their tools or benchmarks; the repository does not maintain a separate reading list.

Keep descriptions concrete. Tell readers what the software does, what it works with, and what it produces. Link installation instructions upstream. Corrections, replacements, and reports of broken projects are welcome.
